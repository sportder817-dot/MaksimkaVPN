# Максимка VPN

Android-проект с интерфейсом VPN и `VpnService`.

Важно: этот проект создаёт VPN-интерфейс, но пока не содержит серверного туннеля, поэтому это НЕ полноценный VPN для выхода в интернет.

## Сборка
1. Открой папку в Android Studio.
2. Дождись Gradle Sync.
3. Подключи Android-телефон с USB debugging или запусти эмулятор.
4. Нажми Run.
5. Для настоящего VPN нужно подключить серверный протокол (например, WireGuard) и конфигурацию сервера.
